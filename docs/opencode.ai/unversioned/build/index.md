# 简介

每天都有数百万人使用 OpenCode。你可以在它之上进行构建，创建自己的应用、集成和 agent 体验，而无需从零开始。

我们还为[插件](plugins/effect/index.md)、[客户端](client/effect/index.md)和[嵌入式应用](sdk/effect/index.md)提供了 Effect API。

<CardGroup cols={1}>
  <Card title="扩展 OpenCode" href="/build/plugins">
    构建插件来添加工具、集成、命令、agent 和自定义行为，同时保持 OpenCode 的其余部分原封不动。
  </Card>
  <Card title="以服务器方式运行" href="/build/client">
    使用与 TUI 和桌面应用相同的客户端连接到 OpenCode，然后围绕它构建任意的界面、工作流或 agent 体验。
  </Card>
  <Card title="嵌入它" href="/build/sdk">
    将 OpenCode 直接嵌入到你的应用中，围绕它构建完全自定义的 agent、界面或开发者产品。
  </Card>
</CardGroup>
