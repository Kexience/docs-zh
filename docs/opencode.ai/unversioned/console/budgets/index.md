# 预算

预算通过策略来限制每月支出。所有者和管理员在 **Controls** 中管理它们。

## 预算级别

| 策略受众                 | 适用于                                     |
| ------------------------ | ------------------------------------------ |
| Entire workspace         | 所有成员与服务账号的合计支出               |
| All members              | 每位成员，或全体成员共享的一个额度         |
| Members tagged with      | 具有所选标签的成员                         |
| These members            | 特定成员                                   |
| All service accounts     | 每个服务账号，或共享的一个额度             |
| These service accounts   | 特定服务账号                               |

一次请求必须低于每一条适用的预算。更大的额度永远不会覆盖更小的那条。没有任何预算时，支出不受限制。

## 工作区预算

工作区预算在工作区达到上限后，会对所有人阻断请求。

1. 打开 **Controls**，点击 **Add policy**。
2. 选择 **Entire workspace**，并添加一条 **Budget** 规则。
3. 输入以美元计的每月上限，点击 **Save**。

## 成员预算

在策略中选择 **All members**，可以为每位成员提供每月额度，也可以让整个组共享一个金额。选择特定成员或标签可以覆盖更小的人群。

要为某个人设置预算：

1. 在 **Settings › Members** 中打开该成员。
2. 点击 **Create budget policy**，构建器会打开并已选中这个人。
3. 输入金额，点击 **Save**。

该成员的页面上会列出适用于他的策略。如果一条全员预算也覆盖到他，两条限制会同时生效。

## 服务账号预算

在 **Controls** 中选择 **All service accounts** 或 **These service accounts**，添加一条 **Budget** 规则，并设置个人或共享的每月额度。该策略覆盖属于这些账号的每一个 key。

## 金额与重置

- 金额以美元计，最多两位小数。
- 预算在每月 1 日 00:00 UTC 重置。
- `$0` 预算会阻断所有计入预算的支出。
- 新增或修改预算时会计入当月已经记录的支出，不会重置额度。

## 计入范围

默认情况下，预算覆盖 **All spend**。你可以把它收窄到选定的模型；此时只有这些模型会计入，可以为这组模型共用一个额度，也可以为每个模型单独设额度。

| 支出                                                        | 是否计入预算               |
| ----------------------------------------------------------- | -------------------------- |
| 付费的 Console 模型                                         | 是                         |
| [自有 provider](../providers/index.md) 上已设置价格的模型    | 是，按配置的价格           |
| [Web 搜索](../websearch/index.md)                           | 是，计入 all-spend 预算    |
| 免费模型                                                    | 否                         |
| 计划内的 [Go](../go/index.md) 用量                          | 否                         |
| 从积分支付的 Go 额外用量                                    | 是                         |

## 达到预算后

在预算重置、或有所有者/管理员调高额度之前，新请求会以 HTTP `429` 失败。响应会指出是策略预算失败，但不会指明是哪条预算。在 **Activity › Logs** 中打开该请求，可以看到拦截它的策略。

```text
Upstream request failed: Policy budget exceeded
```

预算在请求开始时检查。已经在进行中的请求会执行完毕，因此最终支出可能略微超过上限。

## 追踪支出

每位成员都可以在 **Activity** 中看到自己的支出和限额。打开 **My usage** 查看 **Activity › Overview**，其中包含预算明细和重置日期。

所有者和管理员可以从支出图表打开 **Activity › Usage**。它按天、模型和人员细分费用，**Export usage** 按钮可以把最近 7、30 或 90 天的每日总计下载为 CSV。
