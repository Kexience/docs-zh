# 获取帮助

我们希望你觉得 Testcontainers 直观易用、稳定可靠。不过，事情有时并不会如我们预期的那样发展，如果能帮上忙，我们很乐意伸出援手。

如需联系 Testcontainers 团队以及其他用户，你可以：

- 加入我们的 [Slack 团队](https://slack.testcontainers.org)
- [搜索我们的 issue 追踪器](https://github.com/testcontainers/testcontainers-java/issues)，或者在发现任何 bug 或有改进建议时提交新的 issue
- [搜索 Stack Overflow](https://stackoverflow.com/questions/tagged/testcontainers)，尤其是那些带有 `testcontainers` 标签的帖子
