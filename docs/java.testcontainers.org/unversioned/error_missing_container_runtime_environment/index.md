# 解决无法发现受支持的容器运行时环境的问题

如果你来到了这个页面，说明要么是 Testcontainers 没能在你的环境中找到受支持的容器运行时，要么是你在搜索有关 Testcontainers 环境发现机制出错的信息时找到了这里。

Testcontainers 需要环境中存在受支持的容器运行时，才能管理和运行容器。受支持的容器运行时环境如下：

- [Docker Desktop](https://www.docker.com/products/docker-desktop/)
- [Linux 上的 Docker Engine](https://docs.docker.com/engine/install/)
- [Testcontainers Cloud](https://www.testcontainers.cloud?utm_medium=direct&utm_source=testcontainers.com&utm_content=docs&utm_term=on-failure)

有关受支持的容器运行时环境的更多信息，以及其他容器运行时环境的已知限制，请参阅我们文档中的[该页面](../supported_docker_environment/index.md)。
